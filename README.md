## Featured Security Repositories & Assessments

- **[Healthcare Web Application Pentest Case Study](https://github.com/dr-winner/healthcare-pentest-case-study)**  
  Full-scope commercial-style penetration test and security audit report simulating hospital infrastructure. Documents a chained 6-phase kill-chain: SQL injection authentication bypass (`admin ' --`), CWE-204 username enumeration, weak PDF cryptographic cracking via `pdf2john`, document metadata forensics (`exiftool`), and payroll database exfiltration. Includes production PHP PDO prepared statement patches, AES-256 PDF encryption modules, and automated metadata scrubbing scripts.  
  <sub>Penetration Testing · OWASP Top 10 · WSTG v4.2 · SQLi · Cryptanalysis · PHP PDO · Python</sub>

- **[OSINT & Network Reconnaissance Assessment](https://github.com/dr-winner/osint-and-network-recon-assessment)**  
  Multi-vector open-source intelligence (OSINT), external perimeter footprinting, and internal network enumeration assessment. Covers WHOIS/DNS infrastructure profiling, Google Hacking Database (GHDB) query engineering, visual entity relationship mapping with Maltego Graph, passive subdomain discovery via theHarvester, and active subnet service profiling using Nmap/Zenmap.  
  <sub>OSINT · Reconnaissance · Network Scanning · Nmap · Maltego · theHarvester · Attack Surface Management</sub>

- **[AWS Threat Detection & Response Lab](https://github.com/dr-winner/aws-threat-detection-lab)**  
  Detection-as-code security engineering project mapping AWS CloudTrail and GuardDuty findings through Amazon EventBridge rules to automated Python Lambda alerting handlers. Rules mapped to MITRE ATT&CK tactics (root account usage, non-MFA console logins, CloudTrail tampering, IAM persistence, and security group exposures) with automated SNS email and Slack alerting.  
  <sub>Cloud Security · AWS · Detection-as-Code · EventBridge · Lambda · GuardDuty · MITRE ATT&CK · Checkov</sub>
